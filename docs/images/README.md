# Documentation images

`fountain-gardens.png` is a 640×480 capture of the native Vulkan build running
RK5E01 Rev 0 on Linux, captured on 2026-11-13 with experimental GPU-resident copies
and batch texture validation enabled (runtime commit `bd9634e`). It was read from the game's VI-selected
framebuffer. It is not a Dolphin capture, a mock-up or an interpolated image.

The image demonstrates a rendered scene, not frame rate or whole-game support.

extracted assets or raw recordings are included here.
